solana-tx-parse

Any Solana transaction, in words

Give it a signature and get back who paid, what it cost (base and priority fee), whether it failed and why, which programs ran, whose balances moved, the SOL and SPL transfers, and the swaps. Legacy, v0 (address lookup tables) and v1 transactions. Zero dependencies, any RPC.

What it does

  • Fee split into base and priority, plus the priority fee the Compute Budget instructions ask for
  • Failures in words: instruction 2 (Raydium CLMM) failed: custom program error 6001 (0x1771)
  • 18 well-known programs named: Jupiter, Raydium, Orca, Meteora, pump.fun, PumpSwap and more
  • SOL and token balance changes per wallet, exact amounts as strings
  • SOL and SPL transfers, Token and Token-2022, with the owning wallets resolved
  • Swaps from balance deltas, for any DEX
  • Address lookup tables merged; v1 transactions fetched with the version the RPC asks for

Use it in your code

npm install github:blixvip/solana-tx-parse
import { parseTransaction } from "solana-tx-parse";

const tx = await parseTransaction("x2nTgvSFFneAKW5W5mHcfMYhzen5o7Lfb1pBmepDQQDJZ4ud2Z7QpDxdYVVTVMDqG2e5TJ1qAA8zGDPAxdpudKR");

console.log(tx.status, tx.feePayer);
console.log(tx.fee.lamports, tx.fee.baseLamports, tx.fee.priorityLamports);
for (const t of tx.transfers) console.log(t.fromOwner, "->", t.toOwner, t.amount, t.mint);

Already have the transaction from a websocket or your own client? parseFetchedTransaction(tx) parses it synchronously with no network. Full documentation and every result field are in the README and API reference. MIT licensed, no dependencies.

Integrations

  • A JSON endpoint: GET /tx/<signature> with node:http, no framework
  • A Discord webhook alert: post a transaction summary to a channel
